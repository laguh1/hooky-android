## ⚠️ Data quality note — read before using this list

The Spain groups doc has precise member counts and posts/day for every group. That data almost
certainly came from browsing Facebook directly while logged in — web search does not expose
Facebook group member counts, privacy status, or activity level. The groups below are real (found
via search), but everything else needs to be confirmed by opening each link yourself:

1. Open the link
2. Note: member count, public/private, roughly how many posts/day, whether it's Brazil-specific
   or broader Lusophone (could include Portugal/Angola/Mozambique members)
3. Fill in the table below as you go

If you'd rather delegate this verification step, it can be done via a browser-automation pass
(Claude in Chrome) logged into your own Facebook account — say so and that can be set up.

## Context found during research
General crafting-community signal (unverified, from a blog aggregator, not Facebook itself):
crochet and knitting reportedly have the largest and most active craft communities on Brazilian
WhatsApp, ahead of sewing, painting, biscuit (polymer clay), macramé, and embroidery. Consistent
with the idea that Brazil is a strong market for Hooky, but not a substitute for verifying actual
Facebook group sizes.

## Posting strategy

Same principles as `docs/FACEBOOK-GROUPS.md`:
- Build presence before launching — share real WIP/finished pieces, answer pricing/yarn questions,
  don't lead with "download my app"
- Space launch posts across groups over days/weeks, not all on the same day
- Prioritize the visibility sweet spot (2–20 posts/day) once activity data is known

# Hooky — Social Media Captions & Text Library

Running library of every caption, description, and profile-text snippet drafted for social media —
Instagram, Facebook, and YouTube — so future posts don't require drafting from scratch. Renamed
from `INSTAGRAM-CAPTIONS.md` (Sept 2026) once Facebook Page and YouTube text started living here too.

See `docs/FACEBOOK-GROUPS.md` for Facebook **Group** post copy (different from Facebook **Page**
posts below), `docs/FACEBOOK-GROUPS-BRASIL.md` for the Brazil equivalent, and `docs/VIDEO-SCRIPT.md`
for full video narration scripts. See `docs/PUBLISHING-LOG.md` for the actual posting record (dates,
platforms, links) — this file holds the *text*, that one holds *when/where it went out*.

**Format convention:** post captions lead with the language flag (🇬🇧 / 🇪🇸 / 🇧🇷), per the
multi-language Highlights system on `hooky.app` (see memory `project_hooky_promo.md`). Since Sept
2026 the team is Brazil-only for new social content — see "Current focus" note below.

**Current focus (as of Sept 2026):** all *new* social media content targets the Brazilian market
only (PT-BR). EN/ES entries below are kept for reference, not being actively expanded right now.
